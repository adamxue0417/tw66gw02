# 蓝牙单功能上电与通信测试链

## 测试目标

固件上电后仅初始化 GPIO、DMA、USART1（115200、8N1、无流控）和用于显示测试结果的 C8721 屏幕；给蓝牙模组供电并释放复位。不启动 ADC、温度采集、按键、蜂鸣器、主控状态机或 USART2。

## 固件自动测试链

1. PB3（`POWER_EN`）与 PA11 关闭，PA12 拉低复位；等待 20 ms。
2. PB3 拉高打开主电源，等待 20 ms；PA11 拉高打开蓝牙电源，等待 50 ms；PA12 拉高释放复位，等待模组启动 500 ms。
3. 向 USART1 依次发送下列 AT 命令。每步等待响应，1.5 s 超时，最多重试两次；失败即关断 PA11/PA12 并进入 `BLE_TEST_FAIL`。

| 步骤 | 发送 | 通过条件 |
| --- | --- | --- |
| 链路存活 | `AT\r\n` | `OK` |
| 固件识别 | `AT+GMR\r\n` | `OK` |
| 打开 BLE 事件 | `AT+SYSMSG=4\r\n` | `OK` |
| 修改设备名称 | `AT+BLENAME="apple"\r\n` | `OK` |
| 核验设备名称 | `AT+BLENAME?\r\n` | 含 `+BLENAME:"apple"` |
| 读取地址 | `AT+BLEADDR?\r\n` | 含 `+BLEADDR:` |
| 开始广播 | `AT+BLEADVSTART\r\n` | `OK` |

4. 在手机 BLE 工具或合家亲 APP 连接后，固件收到 `+BLECONN`，屏幕上的蓝牙图标立即常亮，数字区域保持熄灭；然后等待上位机打开 Transparent 服务的 Data Out Notify 后的 `+NOTIFY_ENABLED`。
5. 固件发送 `AT+BLEGATTSNTFY=4\r\n`，收到 `>` 后发送 `TEST` 四个字节。模组应回 `+SEND_OK`，手机应收到 ASCII `TEST`。

## 只有控制器和手机时的测试方法

1. 将当前测试固件烧录到控制器，关闭电源后重新上电。
2. 手机上打开支持 BLE GATT 的调试工具并立即扫描。固件会先把蓝牙名称修改为 `apple`，实际广播名称可能按模组规则显示为 `apple_XXXX`。
3. 在广播开始后的 30 秒内连接该设备。连接成功后，控制器屏幕上的蓝牙图标必须常亮；这表示 MCU 已经从蓝牙模组收到 `+BLECONN`。
4. 在连接后的 30 秒内，找到 Transparent Service 中带 `Notify` 属性的 Data Out 特征并打开通知订阅。
5. 手机通知窗口应收到以下数据：

```text
HEX：54 45 53 54
ASCII：TEST
```

同时满足“蓝牙图标常亮”和“手机收到 `TEST`”，即可判定供电、复位、UART AT 指令、名称修改、BLE 广播、连接和 MCU 到手机的数据链路全部通过。

若 30 秒内没有连接，或连接后 30 秒内没有打开 Notify，固件会进入 `BLE_TEST_FAIL` 并关闭 PB3 `POWER_EN` 和 PA11 `BT_PWR_EN`。此时需要重新给控制器上电再测。

## 人工判定与故障定位

| 现象 | 判定 / 排查 |
| --- | --- |
| `AT` 没有 `OK` | 检查 PA11/PA12 时序、USART1 PA9/PA10 是否交叉连接、115200 8N1、共地及模组 3.3 V。 |
| 有 `OK` 但无广播 | 执行 `AT+BLEADVSTART`，再检查 APP 扫描权限；`AT+BLENAME?` 应返回 `apple`。实际广播名称可能按模组规则附加 MAC 地址后缀。 |
| 已连接但无 `+NOTIFY_ENABLED` | 手机端必须订阅 Transparent 服务 Data Out 的 Notification。 |
| 收到 `+SEND_CANCELED` / `+SEND_ERROR` | 连接或 Notify 已撤销；重新连接并订阅后重测。 |

## 合家亲专用协议扩展（配置完成后）

要接入合家亲，先由生产配置工具写入真实产品资料，不能使用示例中的占位信息：

```text
AT+CMPD="<id>","<token>","<vendor>","<brand>","<model>","<power>"
AT+CMDEV="<sn>","<cmei>"
AT+CMVER="<version>"
```

随后用 `0x02` 网络状态帧确认连接/登录，并对每一帧回复同序列号、长度为 `0x0000` 的确认帧。Host 上报合家亲业务数据使用 `0x06`，数据为 `CommandID | Key | Encrypt | Timestamp(4B, 可全 0) | Data`；帧头 `55 AA`、版本 `03`、长度为大端、末尾校验为从帧头起的所有字节和对 256 取模。完整帧不得超过 128 字节。

本测试固件刻意只覆盖 AT/Transparent 链路。合家亲业务帧测试必须使用中国移动提供的有效 CommandID、Key、Token 和账户登录环境。
